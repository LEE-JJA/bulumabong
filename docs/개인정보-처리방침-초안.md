# 개인정보 처리방침과 동의 화면 (초안)

> **초안입니다.** 로그인(학생 학교 메일 인증, 기관 담당자 계정)이 들어간 뒤를 가정해 썼습니다. 실제 공개 전에 개인정보보호 전문가나 법률 검토를 받아야 합니다. `[ ]` 안은 정해서 채울 곳입니다.

## 먼저 정해야 할 것

| 항목 | 왜 필요한가 | 선택지 |
|---|---|---|
| 운영 주체(개인정보처리자) | 처리방침의 주어. 책임과 연락처가 여기 걸림 | 팀(개인 또는 법인), 대학, 자원봉사센터 |
| 개인정보 보호책임자 | 법으로 지정해야 함 | 이름·직책·연락처 |
| AI 처리 지역 | 지금 Bedrock이 **미국 동부(us-east-1)** 라 전화 메모가 국외로 감 → 국외 이전 고지·동의가 필요 | 서울 리전(ap-northeast-2)에서 쓸 수 있는 모델로 바꾸면 국외 이전 항목을 지울 수 있음 |
| 기록 보관 기간 | 기간이 정해져야 함 | 예: 탈퇴 즉시 삭제, 봉사 기록은 졸업·탈퇴 후 [1]년 |
| 서버 위치 | 저장소 위치 고지 | AWS 서울 리전 권장 |

## 1. 개인정보 처리방침

**[운영 주체 이름]**(이하 "부루마봉")은 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고, 관련 고충을 신속하게 처리하기 위해 다음과 같이 처리방침을 둡니다.

### 1조. 처리하는 개인정보와 목적

| 누구 | 항목 | 목적 | 필수 여부 |
|---|---|---|---|
| 학생 | 학교 메일 주소, 이름, 소속 대학 | 회원 확인, 한 사람 한 팀 규칙 적용, 대학별 순위 | 필수 |
| 학생 | 사는 곳(읍면동까지만) | 거리 가산점 계산(캠퍼스와 집 중 가까운 곳 기준) | 선택 |
| 시민 서포터 | 메일 주소, 이름, 사는 곳(읍면동까지만) | 회원 확인, 캠퍼스 생활권 판단, 거리 가산점 | 필수 |
| 학생·시민 서포터 | 봉사 신청 내역, 봉사 기록(시설, 날짜, 시간, 점수, 확인 영수증) | 봉사 매칭, 봉사 인증, 점수와 순위 | 필수 |
| 기관 담당자 | 이름, 소속 기관, 업무용 메일 주소 | 담당자 확인, 요청 등록, 확인 코드 발급 | 필수 |
| 모든 이용자 | 접속 IP 주소 | 과도한 요청 차단(서버 메모리에서 1분 단위로만 셈, 저장하지 않음) | 자동 |

- 주민등록번호, 전화번호, 상세 주소는 받지 않습니다.
- 학생의 위치를 실시간으로 수집하지 않습니다. 지도에는 시설별 활동 인원 수만 보입니다.

### 2조. 도움을 요청한 어르신의 정보

- 어르신이 전화로 요청하면 기관 담당자가 요청 내용을 정리해 올립니다. 부루마봉에 올라가는 요청은 **익명**이며, 어르신의 성함·연락처·주소는 학생에게 보이지 않습니다.
- 담당자가 쓴 전화 메모는 요청 카드로 정리하는 데에만 쓰고 **저장하지 않습니다.** 정리 전에 전화번호, 주민등록번호, 상세 주소, 성함 형태의 글자는 자동으로 가립니다.
- 어르신 개인정보의 수집과 보관은 각 기관의 책임 아래 기관의 절차를 따릅니다.

### 3조. 보유 기간

- 회원 정보: 탈퇴할 때까지. 탈퇴하면 [즉시] 삭제합니다.
- 봉사 기록: 졸업·탈퇴 후 [1]년. 학교 봉사 실적 확인 요청에 대비합니다.
- 기관 담당자 정보: 담당자 해지 시까지.
- 법령에 따로 보관 의무가 있으면 그 기간 동안 보관합니다.

### 4조. 제3자 제공

부루마봉은 이용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다만 다음은 이용자가 요청하거나 동의한 경우에만 합니다.

| 받는 곳 | 항목 | 목적 |
|---|---|---|
| 이용자가 신청한 봉사 기관 | 이름, 소속 대학, 신청 일시 | 봉사 참여 확인 |
| 소속 대학 (학생이 요청할 때) | 이름, 봉사 기록 | 비교과 마일리지 등 학교 인정 |

### 5조. 처리 위탁

| 받는 곳 | 맡기는 일 |
|---|---|
| Amazon Web Services | 서버 운영과 데이터 저장, AI 처리(Amazon Bedrock) |

### 6조. 국외 이전 (AI 처리 지역이 국외일 때만)

| 항목 | 내용 |
|---|---|
| 이전받는 곳 | Amazon Web Services, Inc. |
| 이전 국가 | 미국 (us-east-1 리전) |
| 이전 일시와 방법 | 전화 메모를 요청 카드로 정리할 때, 봉사 브리핑을 만들 때 네트워크로 전송 |
| 항목 | 개인정보를 가린 전화 메모, 대학별 점수 현황(개인을 알아볼 수 없음) |
| 목적 | AI로 요청 카드 정리, 브리핑 문장 생성 |
| 보유 기간 | 처리 직후 삭제(Bedrock은 입력을 모델 학습에 쓰지 않음, [AWS 약관 확인 후 기재]) |
| 거부 방법 | 기관 담당자는 전화 메모 대신 직접 쓰기로 요청을 올릴 수 있습니다 |

### 7조. 이용자의 권리

이용자는 언제든 자기 개인정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 앱의 [내 정보] 메뉴나 아래 연락처로 요청하면 [10]일 안에 처리합니다.

### 9조. 안전성 확보 조치

- 접속 기록과 요청 횟수를 제한해 무작위 대입을 막습니다.
- 확인 코드와 기관 키는 서버의 비밀값으로만 계산하고 화면이나 주소에 남기지 않습니다.
- 전송 구간은 HTTPS로 암호화합니다.
- 개인정보를 다루는 사람을 최소한으로 둡니다.

### 2-3. 화면 원칙

- 동의 항목은 미리 체크해 두지 않습니다.
- 선택 항목에 동의하지 않아도 가입과 이용이 됩니다.
- [내 정보]에서 선택 동의를 언제든 철회할 수 있습니다.
- 처리방침은 모든 화면 아래에 "개인정보 처리방침" 링크로 둡니다. 다른 글자보다 눈에 띄게(굵게) 표시합니다.
- 처리방침이 바뀌면 시행 7일 전에 앱 안에서 알립니다.
