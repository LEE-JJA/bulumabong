## 1. 무엇을 만드나

- 배포된 서비스 http://3.106.70.230 을 브라우저로 조작하는 장면을 녹화한 **2분 30초 안팎(2~3분 사이) MP4** 한 개.
- 해상도 1920×1080(안 되면 1280×720), 소리 없음. 대신 **화면 아래에 한국어 자막**을 넣어 지금 무엇을 보여 주는지 설명합니다.
- 결과물: `video/부루마봉-시연.mp4`. 녹화 스크립트는 `scripts/demo-video/`에 둡니다. `video/`와 `scripts/`는 GitHub에 영상 파일을 올리지 않도록 `.gitignore`에 `video/`가 이미 들어 있습니다.
- 대회 사이트 제출은 팀이 직접 합니다. Codex는 파일까지만 만듭니다.

## 2. 서비스 한 줄 설명 (자막을 쓸 때 참고)

부루마봉은 원주에서 도움이 필요한 곳(요양원, 보육원, 혼자 사는 어르신)과 봉사할 사람(원주권 대학생, 주민)을 잇는 봉사 매칭 서비스입니다. 원주권 대학끼리 원주 안에서 쌓은 봉사 시간으로 읍면동마다 1위를 겨루고, 1위인 구역에 그 대학 건물이 서며 2위와 점수 차가 클수록 최대 5층까지 올라갑니다. 손이 부족한 곳(요양원·보육원, 먼 읍·면)일수록 점수가 커서, 경쟁하다 보면 저절로 그런 곳으로 봉사가 갑니다.

**말투 규칙**: 시설·어르신·아이를 빼앗거나 차지하는 대상처럼 쓰지 않습니다. "점령, 뺏다, 정복, 공격, 역습, 작전" 금지. "1위가 되다, 따라오다, 격차를 좁히다, 건물이 내려앉다"를 씁니다. 어르신 이름은 영상에 나오면 안 됩니다(예시 메모에도 실명 대신 아래 예시 그대로).

## 3. 꼭 시연 모드로

- 모든 장면은 **주소 끝에 `#test`**를 붙여서 엽니다: `http://3.106.70.230/#test`, 기관 화면은 `http://3.106.70.230/org.html#test`.
- 시연 모드에서는 요청 날짜가 모두 오늘이고, 확인 코드를 서버 없이 브라우저에서 발급·확인합니다(기관 키 불필요). 기록은 `localStorage`의 `ttbb.demo.*`에 따로 저장됩니다.
- 학생 화면과 기관 화면은 **같은 브라우저 컨텍스트(같은 localStorage)**에서 열어야 기관이 올린 요청이 학생 화면에 보입니다. Playwright에서는 한 `context` 안에서 페이지를 옮겨 다니세요.
- 녹화 시작 전에 깨끗한 새 컨텍스트로 시작합니다(이전 시연 기록이 남지 않게).

## 4. 도구

- Node.js 18 이상 + Playwright(Chromium). `scripts/demo-video/package.json`에 따로 설치하세요. **저장소 루트의 `package.json`에는 의존성을 추가하지 마세요**(본 서비스는 외부 패키지 없이 돕니다).
- 녹화: `browser.newContext({ viewport: {width:1920,height:1080}, recordVideo: { dir, size: {width:1920,height:1080} }, locale: 'ko-KR' })`.
- 변환: ffmpeg로 webm → mp4(H.264, `-pix_fmt yuv420p`, `-movflags +faststart`). ffmpeg가 없으면 설치하거나, 안 되면 webm을 그대로 남기고 알려 주세요.
- 자막: 녹화 중인 페이지에 `page.evaluate`로 화면 아래 고정 자막 막대(검은 반투명 배경, 흰 글씨 34px 이상, 두 줄 이내)를 넣고 장면마다 글자를 바꿉니다. 페이지를 옮길 때마다 다시 넣어야 합니다(`page.addInitScript`로 막대를 만드는 함수를 심어 두면 편함).
- 클릭은 사람이 하는 것처럼 보이게 천천히: 동작 사이 0.8~1.5초 쉬고, 중요한 결과 화면은 3~5초 멈춥니다. 마우스 커서가 영상에 안 보이므로, 누르기 직전에 대상에 잠깐 테두리를 그려 주는 작은 효과를 넣으면 좋습니다.
